# 00_Glossary — 术语库 / Glossary

**目的**：统一 FIDIC / ADNOC / 项目内部的术语与缩写，消除歧义。AI 遇到缩写先查这里。

**来源优先级**：`_Ref/` 与 `_tools/guides/` 中的既有释义 > 合同定义条款 (Clause 1 Definitions) > 通用 FIDIC 惯例。每条尽量注明出处。
