# 06_Case_Studies — 案例库 / Case Studies

**目的**：沉淀本项目真实发生的 RFI / TQ / VO / Claim / Correspondence / NCR 及其**处理与最终结果**，形成可复用经验。这是 AI 最值钱的部分——它让专家有"记忆"。

## 案例模板 / Template
```
案例ID：C-<序号>
类型：RFI / TQ / VO / Claim / NCR / Dispute
事件：发生了什么 + 日期
合同背景：涉及条款 / 实体（链到 01_Entities）
处理：采取的动作 / 发出的通知 / 提交的证据
结果：批准/驳回/金额/工期/教训
可复用点 / Lesson：下次遇到类似情况怎么做
出处 / Source（原始文件路径）
```

> 每个案例都要链回具体实体和条款，AI 才能"由旧案推新案"。空模板，等真实事件填入。
