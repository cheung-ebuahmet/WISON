# 07_QA — 问答库 / Q&A

**目的**：沉淀已确认的专家问答对，快速复用；也是校验知识层是否够用的"考卷"。

## 模板 / Template
```
Q：（问题原文）
A：（结论）
依据：R-xxx / 条款 / 案例 C-xxx / 实体
把握度：高 / 中 / 待核实
日期：
```

## 示例问题（待答）
- 这个 VO 为什么不能付款？
- 业主索赔通知时限是几天？分包是否 back-to-back 一致？
- 预付款回扣怎么算？Retention 何时释放？
- 争议最终去哪解决（DAB / ICC / DIAC / ADCCAC / Abu Dhabi Court）？

> 每个答案必须带依据；无依据的先标"待核实"，不进正式库。
