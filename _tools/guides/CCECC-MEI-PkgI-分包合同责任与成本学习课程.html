责任范围（一）：一条"兜底条款"先记住

责任矩阵里每个专业都反复出现的两句兜底话，是整套合同的责任边界总开关。
清单只列"特殊分配"，没列的全甩给分包。

在责任矩阵里，每个专业（钢结构、管道、设备、电仪、暖通……）都反复出现两句一模一样的兜底话：

"Any or all necessary materials not mentioned above will be supplied by the Subcontractor."

（没写到的料，一律分包商自己买。）

"Any or all necessary work not mentioned above will be done by the Subcontractor."

（没写到的活，一律分包商干。）

配套还有一句卸车责任（几乎每个专业都有）：

"The Subcontractor will be responsible for unloading of the CONTRACTOR-supplied materials/elements delivered to the WORK SITE / SUBCONTRACTOR warehouses / laydown areas inside the PROJECT SITE."

（总包供的料送到现场 / 分包仓库 / 堆放区，卸车是分包的。）

学习要点：这类"清单 + 兜底"结构是国际分包合同的固定套路。看责任矩阵时，别只盯着"谁打 X"，要看"谁没打 X 但又被兜底条款覆盖"——那才是责任真正落在谁头上的地方。

责任范围（二）：X / A 记号与"谁买料"

责任矩阵用两个记号标记三个主角之间的分配。
永久工程实体料 → 总包买；消耗/临时料 + 所有施工动作 → 分包买、分包干。

文件开头定义了两个记号：X = Perform（做），A = Assist（协助）。三个主角：OWNER（业主 ADNOC Gas）、CONTR（总包 = Wison）、SUBCO（分包 = CCECC）。

① 谁买"永久材料"——总包买为主

材料类别谁买示例
设备 / 罐 / 管材管件 / 阀门法兰CONTR设备、罐、管、阀、特殊支架（弹簧支架）、成品钢结构
分包自购型钢与辅材SUBCO管支架型钢原料、保温/油漆、电气小件辅材、测试介质、消耗品

② 谁买"消耗 / 临时材料"——分包买

  • 焊条焊丝、气体、砂轮片、临时支架、试压盲板、冲洗用水用气、脚手架 → 全部 SUBCO

③ 谁卸车、谁搬运——几乎全是分包

责任矩阵 D 节第 5 项明确：总包供的材料设备送到现场/仓库/堆放区，装卸、从总包仓库搬到分包堆场，全是 SUBCO（打 X）。

④ 谁做重件吊装——分包

  • "Heavy Lifting will be part of SUBCONTRACTOR's scope"（重吊在分包范围）
  • 连"重件运输道路修整、地基承载力第三方检测"也是分包（H 节 4.1–4.4）

⑤ 谁做检验测试——分包，总包只协助

  • RT/MT/UT/PT、PWHT、水压试验、化学清洗、PSV 校验 → SUBCO X
  • 焊工考试 WPQ 的试件材料分包自备（I 节第 5 项专门写了）
记忆抓手：凡是"永久工程实体料"（管、阀、设备、钢结构成品）→ 总包买；凡是"干活用的消耗/临时料 + 所有施工动作"→ 分包买、分包干。唯一例外是少数写明的 "A（协助）" 项。

成本（一）：BOQ 怎么算钱——六个成本要素

打开 Appendix D BOQ，列头是理解成本的关键。
每单位工程量 = 人工 + 材料 + 工器具 + 机械，四要素加总为直接成本。
专业明细表列头（如 Piping Green）
列含义你的关注点
UNIT计量单位（Dia-Inch / set / EA / m）算量依据
Qty工程量估算量
MANHOURS (A)工时人工
LABOR COST (B)人工单价人工费
MATERIAL COST (C)材料单价材料费
TOOLS & CONSUMABLE (D)工器具 / 消耗品单价工器具费
EQUIPMENT COST (E)机械单价机械费
DIRECT COST (F)= B+C+D+E 直接成本合计直接费

公式（表头第 9 行写得很清楚）：F = B + C + D + E，每个 Amount = Qty × 单价。

成本拆解的核心：这套 BOQ 的报价逻辑是"每单位工程量 = 人工 + 材料 + 工器具 + 机械 四要素加总"。你要评估一个分包报价合不合理，就看这四个单价拆得对不对——这就是"工艺拆分及其报价"的落点。

实例（Piping Green 真实数据）

编号描述单位Qty直接成本单价

Dia-Inch（焊口英寸）是管道焊接的经典计量单位：管径(英寸) × 焊口数。一个 8 寸管焊一个口 = 8 Dia-Inch。这是管道算量的核心概念，务必记住。

注意事项：执行期容易踩的坑

结合计价指令 Exh D.0 里的兜底条款，挑最要命的几条。
固定单价 + 估算量 + 漏报归零 + 全甩分包，是这套合同的四条铁律。
条款内容风险与应对
1.17除 Matrix 写明由总包供的，其余全部材料分包自供现场最常扯皮"这个料谁买"。签合同前逐项核对 Matrix，别信"口头答应供"
1.15工程量是估算，量多量少单价都不变分包不能因量差调价，风险全在分包
1.12单价锁定，不因成本/汇率波动调整分包吃定所有涨价风险
1.7 / 1.20漏报的项 = 0 元；含零量项也要报价投标时每个带 Qty 的项都要报价
1.32拆除/废项单价 = 对应安装单价的 30%变更计价时这是现成费率依据，别重新谈
1.16新单价参照现有类似单价内插变更谈判时总包可用此压分包新价
—重吊是分包范围（含道路修整、地基第三方检测）分包极易低估，投标要单独盘
—总包供料到现场，卸车是分包的大型设备到场卸车高风险高成本，报价要含

瑕疵清单与下次招标风险

同事出具的这版 BOQ，招标时的版本并不完美。分"已确认"与"需复核"两类。
最严重是管理费+利润留空，其次是四要素单价未拆分，导致变更时无谈判抓手。

✅ 已确认的瑕疵

#瑕疵位置风险
1确认 G01 总部管理费、H01 利润金额留空A.1 第 49、53 行分包可能"零利润/零管理费"报价后靠变更找补，或漏报导致总价失真
2确认 "TOTA" 拼写错误（TOTAL 少 L）A-Summary 第 35–36 行校核不严，暗示其他数字也可能有错
3确认 间接费金额呈"整齐凑数"规律A.1 各 Lump Sum268,000 / 536,000 / 804,000 / 1,206,000 / 8,040,000 呈倍数 → 疑似占位值，非逐项真实报价
4确认 四要素单价拆分列疑似未填各专业明细 B/C/D/E 列数据行只见综合直接成本单价，四要素空 → 变更时无法逐要素调价

⚠️ 需你复核（疑似公式未计算）

#观察怎么复核
5待复核 A-Summary 的 Manhours、SUBTOTAL COST 列全空Excel 打开看是"公式未刷新"还是"真没填"。若真没填，总价汇总断链
6待复核 明细表 Qty 有值、但 Amount 列空看 =Q*a 等公式是否有缓存值

📋 下次招标的改进建议（风险应对）

  1. 强制四要素单价拆分填报：要求分包对每个 BOQ 项报出 B/C/D/E 四个单价，而非一个综合价，变更、调量、材差才有谈判抓手。
  2. G/H（管理费+利润）不得留空：设为必填，并与直接费+间接费挂钩核对利润率合理性。
  3. 间接费逐项要求"报价说明"：打破"凑整数占位"，让分包说明每个 Lump Sum 构成（人数 × 工期 × 单价）。
  4. 建立"量-价"对账模板：估算 Qty 与 IFC 图量定期对账（呼应 1.15），提前暴露量差风险。
  5. 拼写/公式校核走查：发布 BOQ 前用脚本跑一遍"空值 + 公式断链 + 拼写"检查。
  6. 把 1.32（拆除=30%）、1.16（新价内插）、费率表写进"变更计价操作卡"，让现场人员知道有哪些现成费率可引用，减少扯皮。
